# 动效序列制作规范（防虚影/防残留/防闪烁）

> 来源：去年夏天（qn）序列返工的完整经验。做新歌专属画面/新动作时按此流程走。
> 配套工具：`qn_重修.py`（RVM 抠像模板）、`序列体检.py`（质量量化）。

## 1. 选材（决定上限，最重要）

| 原则 | 原因 |
|---|---|
| 码率优先 | 虚化的第一大来源是**视频压缩**，不是抠像。B 站 1Mbps 的 1080p 一动就糊；能拿到高码率/原画质就用 |
| 固定机位 > 运动镜头 | 固定机位才能做封闭区清除、背景 median 稳定化 |
| 纯色/绿幕背景 > 复杂背景 | 绿幕走 chroma 路径，边缘硬、零残留 |
| 避开镜头切换与快速甩动 | 运动模糊烙在源帧里，任何算法都救不回来；选"唱得动但晃得少"的段落 |

## 2. 抽帧

- **禁用时域降噪**：`hqdn3d` 的时间分量会把移动物体拖出重影（qn 返工实测）。空间降噪可少量用：`hqdn3d=3:2:0:0`
- 按源帧率抽帧再取样，别用滤波混合帧

## 3. 抠像（核心）

1. **RVM 时序抠像打底**（`qn_重修.py` 是完整模板）：帧间记忆 = 轮廓稳定，天生防"部位消失/闪烁"。GPU 上 ~0.1s/帧
2. **永远用原始帧颜色 + 模型 alpha**，不要用 RVM 的 fgr 前景重建——fgr 会把移动细节（琴身、手持物）糊掉
3. **alpha 二值化（>0.5）+ binary_fill_holes + 1px 羽化（gaussian 0.8）= 反虚影核心步骤**。
   虚影的本质是中间透明度（0.2-0.7 的拖尾），二值化直接砍掉；羽化只给 1px，更宽=人为虚化
4. RVM 实心阈值按素材调：一般 0.5；若背景被误判成半透明前景（封闭窗景类），提到 0.85
5. **封闭背景区**（被手臂/乐器/身体围住的窗景、墙面）是残留重灾区，两个模型都会误判：
   - 先跑诊断三联图（源图 / rm / u2net）确认元凶
   - 用画布坐标精确测量，转成素材帧坐标时**务必加上 union bbox 偏移 (x0,y0)**——这是 qn 返工中最大的坑
   - 矩形内清零 + `~dilate(rm,3)` 保护身体；矩形边界要避开琴颈等需要保留的细节
6. u2net 仅用于补 RVM 缺失的高对比细节（如吉他），贡献门控在身体邻近区，并用 `clean_alpha` 清小碎块

## 4. 合成

- 透明区 RGB 必须清零（`rgb[a<8]=0`），否则 LANCZOS/bicubic 缩放时会晕出脏边
- 统一画布贴底居中，union bbox 统一缩放（沿用 `预处理.py` 的 stage_actions 逻辑）

## 5. 体检（交付前必跑）

```
python 工具/序列体检.py 凑企鹅/资产/<序列名>
```

- **ghost 虚影占比**：来自 1px 羽化属正常（~2%）；>8% 说明有真虚影
- **flick 帧间闪烁**：慢动作序列中位数应 <5；快动作序列此指标不可诊断（真实运动也会很大）
- **resid 孤立残留**：持续高值可能是合法分离件（甩出的手脚），离群尖峰才是问题
- 判定是"序列内离群检测"：相对本序列中位数的尖峰才有意义
- 标记帧用体检拼图人工过目，再决定是否返工
