# 🐧 凑企鹅桌宠

一只住在 Windows 桌面上的凑企鹅（高松灯）桌宠——透明窗口、逐像素点击穿透、多动作、每首歌专属画面。

> 灵感与技术致敬：[yugh6/Naiwa](https://github.com/yugh6/Naiwa)（C# 桌宠基座）·
> [Diyeego/naiwa-pet](https://github.com/Diyeego/naiwa-pet)（行为参考）

## ⬇️ 下载桌宠（三步，不用懂编程）

### [👉 点这里下载 tomorin-pet-v1.0.zip](https://github.com/yueganw-prog/tomorin-pet/releases/latest/download/tomorin-pet-v1.0.zip)

1. 下载上面的 zip（没反应的话：仓库右上角 **Releases** → 最新版本 → `tomorin-pet-v1.0.zip`）
2. 解压到任意文件夹
3. 双击 `凑企鹅桌宠.exe`——企鹅就会出现在屏幕右下角 🐧

杀毒软件提示时选"允许 / 信任"即可（无签名小工具的正常待遇）。

包内自带六首 AI 高松灯翻唱（billie jean / cry for me / just two of us / 雨爱 / L的小曲 / 去年夏天），
每首都有专属演出画面。想换歌就把你的 mp3 / m4a 丢进 `music` 文件夹，重启桌宠即可。

## 📖 全部玩法

凑企鹅桌宠 · 使用说明 1.0

双击「凑企鹅桌宠.exe」启动（需与 素材.nwp 同目录）。

── 交互 ──
1. 待机：轻微浮动 + 呼吸，每隔几秒眨一次眼（找企鹅：双击托盘图标）
2. 单击肚子：果冻戳（无声）
3. 双击：播放 19 秒「通透」名场面 + 原声
4. 按住拖动：移动，身体随方向倾斜；快速甩出松手 = 物理甩飞（重力、边缘反弹）
5. 全屏看视频/打游戏时自动隐藏，退出全屏自动回来

── 右键菜单 ──
通透一下（双击）/ 停止播放 / 唱歌 / 动作 ▸ 跳舞 · 飞踢 · 饿倒
· 唱歌：循环播放 music 文件夹里的歌，每首歌有专属画面，屏幕下方控制栏可切歌
· 跳舞 / 飞踢 / 饿倒：一次性动作，播完自动回待机
    饿倒带「饿啊～」哭喊音效；跳舞、飞踢也带各自原声
通透原声：双击时是否播放原声（✓ 开）
大小：小号 / 标准 / 大号
总在最上面：开 = 企鹅悬浮在所有窗口之上（浏览器、文档都盖不住它，陪伴感强，
    但可能挡住正在看的内容；透明区域不挡鼠标，只挡视线）
    关 = 变成普通窗口，会被其他窗口挡住，桌面空着或窗口最小化时才露出
    （建议：摸鱼时开、认真工作时关）
全屏时自动隐藏：进全屏（看视频/游戏）企鹅躲起来，退出全屏自动回来
回到屏幕右下角：找不到企鹅时点它
随机说话：开启后每 2 分半随机弹出台词库一句话（显示 15 秒），整点优先报时
编辑台词：打开台词文件，每行一句，改完保存下一轮即生效
    占位符：{time}=当前时间 {hour}=小时 {minutes}=陪伴分钟数
    所有台词（启动问候/报时/随机）都只从这个文件取
开机自启动：开机后企鹅自动出现（右键菜单可开关）
退出凑企鹅

── 文件说明 ──
素材.nwp            全部形象与动作帧（勿删）
通透.wav            双击时的原声
dance/jump/hungry.wav  跳舞、飞踢、饿倒的动作原声
music/              歌曲文件夹（mp3/m4a/wav/flac/ogg），放入后重启生效

── 数据位置 ──
设置与陪伴时长：%LOCALAPPDATA%\NaiwaDesktopPet-tomorin\
台词列表：      %LOCALAPPDATA%\NaiwaDesktopPet-tomorin\lines.txt


## 🔧 从源码构建（面向开发者）

需要：Windows + .NET Framework 4.x（系统自带）+ Python 3.11（仅素材管线）

```
git clone https://github.com/你的用户名/tomorin-pet.git
cd tomorin-pet/源码
build.cmd        # 编译出 exe（csc 编译，零依赖）
```

素材流水线（改形象/加动作/换音效）：

```
cd 工具
pip install pillow scipy rembg imageio-ffmpeg
python 预处理.py actions   # 绿幕/AI 抠图生成动作帧
python 预处理.py pack      # 打包 素材.nwp
```

架构一句话：C# 侧是通用的「动作序列库 + 歌曲映射表」，新动作 = 帧文件夹 + metadata 一行，零代码改动。
